Open Engine · Game engine

Open Engine

A real-time MIT licenced engine for building worlds, designing gameplay, and bringing your games to life.

Explore features ↗View roadmap ↗
  • 01 · Rendering

    GPU-driven from the start

    Bindless, GPU-driven rendering with Vulkan first-class on Windows and Linux, and Metal first-class on macOS.

  • 02 · Shading

    Physically based

    PBR materials with OpenPBR support, shaders, image-based lighting, and real-world light values form the default rendering workflow.

  • 03 · Runtime

    Data-oriented ECS

    A data-oriented entity-component stack is the default, built for clear composition, scheduling, and scale.

  • 04 · Interface

    Data-driven UI

    XML/HTML structure and CSS-style presentation support fast iteration with live editing and hot reload.

  • 05 · Scripting

    C# or C++

    The editor detects user code, compiles CoreCLR-backed C# or native C++, and keeps iteration moving with hot reload.

  • 06 · Extensibility

    Packages and plugins

    Jolt Physics integration ships as a core engine package, but can be swapped out through packages.

  • 07 · Post FX

    Cinematic post-processing

    Post-processing stack for bloom, tonemapping, exposure, film simulation, depth of field, lens flares, chromatic aberration, and stylized painting effects.

  • 08 · UI toolkit

    Interface built to iterate

    Yoga-powered layouts, CSS-style presentation, layered controls, Slug text rendering, and hot reload support responsive game interfaces.
