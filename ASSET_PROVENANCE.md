# Asset provenance

## Open Engine project media

The following website media was supplied by the Open Engine project maintainer for publication:

- Open Engine cube marks, favicons, and social preview artwork.
- Screenshots under `public/images/editor-captures/` and the editor overview artwork used by the
  feature and homepage pages.
- Generated roadmap illustrations and documentation diagrams.

Editor screenshots may visibly contain project test scenes, textures, models, or artwork. Those
embedded works retain their original rights and licenses. The website code license does not grant
permission to extract or redistribute them independently.

## Publication rule for new assets

Before adding a third-party image, icon, font, model, texture, or screenshot:

1. Record the creator, original URL, and exact license or written permission.
2. Confirm that marketing/web redistribution and derivative crops are permitted.
3. Add the required attribution to `THIRD_PARTY_NOTICES.md`.
4. Remove private paths, account names, credentials, and unnecessary metadata.

Assets without a traceable source or permission record should not be added to a public release.
